## Closed historical issues that must not be misdiagnosed as current by default

- Object Resolver unbounded object creation: historically proven and corrected. Treat as regression check.
- PVF `stop()` method / internal event name collision: historically corrected and validated; unrelated to Vision detection quality.
- July22 harness RSS false-fail: methodology error caused by counting expected post-shutdown memory release as an absolute delta failure.

## Hypothesis promotion rule

A hypothesis becomes `CURRENT ROOT CAUSE VERIFIED` only when:

1. the current authoritative trace places the first divergence at its claimed boundary;
2. a measurement directly observes the incorrect/expensive behavior;
3. a one-variable A/B changes the target symptom as predicted;
4. matched HQ and system regressions remain clean; and
5. the result is independently reviewed.

Until then, no hypothesis authorizes a fix.
