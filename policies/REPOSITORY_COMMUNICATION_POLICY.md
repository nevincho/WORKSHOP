# REPOSITORY COMMUNICATION POLICY

STATUS: MANDATORY
APPLIES TO: ALL AGENTS, CONTROLLERS, CODEX HANDOFFS

WORKSHOP repository artifacts are the only authoritative communication channel between roles.

All substantive analysis, plans, findings, evidence, blockers, handoffs, validation results, decisions, status updates, checkpoints and reports MUST be persisted in nevincho/WORKSHOP.

Agent chats are transport/control interfaces only. Chat history is never project state and must not be used as authority.

When manually triggered, agent chat output must be limited to WORKSHOP UPDATED or WORKSHOP NOT UPDATED unless Control Room policy explicitly requires otherwise.

Cross-role communication occurs through task/evidence/handoff/review artifacts. Do not rely on conversational messages between roles.

If repository write is unavailable, do not place substantive fallback content in chat; report WORKSHOP NOT UPDATED and preserve no unverified completion claim.
