# VALIDATION POLICY

STATUS: MANDATORY
APPLIES TO: ALL AGENTS, CODEX, AUTOMATIONS
OVERRIDE: ONLY VLAD / WORKSHOP CONTROL ROOM

1. PASS requires evidence that measures the stated objective.
2. Verify prerequisites existed before interpreting test results.
3. Distinguish implementation failure from environment, integration, test-harness, and methodology failure.
4. Another agent's report is not proof.
5. Preserve rollback capability and validated behaviour.
6. If evidence is unavailable, report NOT VERIFIED.
