# WORKSHOP Blocker Schema

STATUS: MANDATORY FORMAT

Each blocker record must include:
- TASK_ID
- PROJECT
- BLOCKER_TYPE: ACCESS / PREREQUISITE / ARCHITECTURE / VALIDATION / CREDENTIAL / HARDWARE / PROTECTED_SCOPE / OTHER
- EXACT_BLOCKER
- EVIDENCE
- ROOT_CAUSE if established
- AFFECTED_DEPENDENCY_CHAIN
- SAFE_CURRENT_CHECKPOINT
- SMALLEST_REQUIRED_UNBLOCK_ACTION
- HUMAN_DECISION_REQUIRED: YES / NO
- INDEPENDENT_WORK_ALLOWED
- NOT_VERIFIED_ITEMS

Do not use downstream symptoms as blocker description when the root cause is known. If the root cause is not established, say NOT VERIFIED.
