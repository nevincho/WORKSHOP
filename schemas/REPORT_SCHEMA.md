# WORKSHOP Report Schema

STATUS: MANDATORY FORMAT

Each 8h/12h/24h report must include:
- REPORT_TYPE: 8H / 12H / 24H
- WINDOW_START / WINDOW_END
- PROJECTS_PROCESSED
- TASKS_COMPLETED_VALIDATED
- TASKS_IN_PROGRESS
- TASKS_REWORKED_OR_FAILED
- BLOCKERS_AND_ROOT_CAUSES
- CURRENT_VALIDATED_CHECKPOINTS
- CODEX_USAGE_AND_JUSTIFICATION
- PROTECTED_COMPONENT_STATUS
- TESTS_RUN_AND_OBJECTIVES_MEASURED
- NOT_VERIFIED_ITEMS
- NEXT_ELIGIBLE_TASKS
- HUMAN_DECISIONS_REQUIRED
- EVIDENCE_LINKS

Reports summarize evidence; they never establish completion by themselves. Every completion/validation claim must point to task/review/checkpoint evidence.
