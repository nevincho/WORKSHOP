# WORKSHOP Handoff Schema

STATUS: MANDATORY FORMAT

Each handoff must include:
- TASK_ID
- FROM_ROLE
- TO_ROLE
- PROJECT
- OBJECTIVE
- VERIFIED_CURRENT_STATE
- SOURCE_EVIDENCE
- PREREQUISITES
- AFFECTED_COMPONENTS
- PROTECTED_COMPONENTS
- EXACT_REQUESTED_ACTION
- NON_GOALS
- ACCEPTANCE_CRITERIA
- VALIDATION_METHOD
- PRE_CHANGE_CHECKPOINT
- ROLLBACK_METHOD
- EXECUTION_ACCESS_STATE
- CODEX_JUSTIFICATION if applicable

A handoff must be sufficient for the receiving role to act without relying on prior chat context.
